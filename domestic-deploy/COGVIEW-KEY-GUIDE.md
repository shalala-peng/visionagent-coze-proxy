# 智谱 AI 图像生成 API Key 获取指南（约 5 分钟）

> 用途：给 VisionAgent 的「场景生成 / AI 调色」节点接**真实图像生成 API**，
> 让流水线跑完真出一张 AI 图，审片台审真实图。全程网页操作，不用下载软件。

---

## 1. 打开注册页

浏览器访问：**https://open.bigmodel.cn**

（智谱 AI 开放平台，国内网站，不用梯子）

## 2. 注册 / 登录

- 右上角 **注册**（或直接微信扫码登录）
- 按提示完成注册即可（手机号 + 验证码），**无需实名/绑卡**
- 新用户自动送免费额度（图像生成 CogView 有免费次数，Demo 用绰绰有余）

## 3. 创建 API 密钥

1. 登录后进入 **控制台**
2. 左侧菜单找 **「API 密钥」**（或顶部个人中心 → API Keys）
3. 点 **「创建 API 密钥」**
4. 名称随便填（如 `visionagent-demo`）
5. 生成后点 **复制**，会得到一串以 **`sk-`** 开头的密钥，例如：
   ```
   sk-4f8a2c9b7e1d4c6f90ab1234567890abcdef
   ```

## 4. 把密钥发给我

把 `sk-` 开头的整串密钥粘贴发到对话里（就和之前发扣子 PAT 一样）。

**我不会把它写进任何代码/网页**，只配置到腾讯云函数的环境变量里（和 COZE_API_KEY 同级），浏览器和 GitHub 仓库都不落 Key，安全。

---

## 拿到 Key 后我会做什么（3 步收尾，你只需要点几下）

1. 云函数加环境变量 `COGVIEW_API_KEY` = 你的密钥 → **部署**
2. 重新粘贴我改好的 `index.js`（已内置图像接口，等你确认 Key 后再贴）
3. 重新上传 `index.html` 到 GitHub → Pages 自动重建

之后线上 Demo：生成工作流 → 点运行 → 「场景生成」节点**真实调用 AI 出图**（约 5~15 秒）→ 审片台显示真实 AI 图 → 打回重做再出一张新的。

> 小提示：免费额度用完后图像接口会自动降级回占位图（不影响演示），放心。
