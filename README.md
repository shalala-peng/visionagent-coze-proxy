## 一句话定位

VisionAgent 是视觉生产流程的**智能编排层**：用户输入一句自然语言需求（例如"给婚纱客片做修图→客户审片→不满意打回→通过的出竖版发小红书"），Agent 自动把这句话拆解成一条**有向图生产线**——节点是各类视觉 Skill（抠图 / 调色 / 场景生成 / 合规审核 / 多平台发布），连线是执行顺序，红色打回边代表"审核不过就退回上游重做"。

它不亲自处理像素，而是把视觉团队"每次都要重新想一遍"的流程，变成**一次搭建、反复运行、可存模板复用**的资产。

## 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│  GitHub Pages（静态前端，11 页可交互 Demo）                    │
│  ① 用户输入需求（前端模型选择器选底层 LLM）                    │
│  ② 运行流水线 → 图像/抠图/审核节点真实请求后端                 │
└───────────────────────────┬─────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────┐
│  腾讯云 SCF 云函数（编排代理层，Node 18 零依赖）               │
│  · 代持 COZE_API_KEY   → 扣子智能体（NL→生产线，可选通道）     │
│  · 代持 LLM_API_KEY/*  → OpenAI 兼容多模型路由（可切换厂商）   │
│  · 代持 DASHSCOPE_API_KEY → 通义万相（图生图 / 真实抠图去背景） │
│  · 代持 COGVIEW_API_KEY → 智谱图像生成（兜底出图）             │
│  · 代持 COS_*          → 素材上传后给视觉模型"亲眼看"          │
│  · 代持 ALIYUN_AK/SK   → 阿里云内容安全（合规审核，预留）      │
│  密钥只存在于环境变量，浏览器/仓库零泄露                       │
└───────────────────────────┬─────────────────────────────────┘
                             ▼
        ┌────────────────────────┐      ┌────────────────────────┐
        │ 视觉模型（看图）          │      │ 文本/编排模型（拆线）    │
        │ 扣子豆包视觉 / 万相 / GLM │      │ 扣子 / DeepSeek / Kimi   │
        │ CogView（出图兜底）       │      │ / 通义 / 本地 Ollama    │
        └────────────────────────┘      └────────────────────────┘
                             ▼
           前端 layoutLine 分层布局 → 渲染画布
           → 运行引擎逐节点执行 → 审片台人工审核
           → 打回重做 / 通过发布 → 数据复盘
```

**设计要点**
- **Key 安全**：所有 API Key 只存在于云函数环境变量，浏览器与仓库均不落 Key。
- **跨域**：云函数返回 `Access-Control-Allow-Origin: *`，前端可直连。
- **多模型热切换（OpenAI 兼容架构）**：后端不绑定任何厂商，通过 `LLM_PROVIDER` 环境变量或前端请求级 `llmProvider` 覆盖；只要填 `LLM_BASE_URL` 即可接入任意 OpenAI 兼容端点（DeepSeek / Kimi / 通义 / 本地 Ollama / 聚合网关）。
- **视觉分流**：带素材图时自动走视觉模型（扣子豆包视觉 bot / 通义万相 / 智谱 GLM-4V），纯文本模型（DeepSeek）则不硬传图避免报错。
- **真实 vs 降级**：网络异常、无额度或万相失败（图过小等）时，抠图/出图自动降级（CogView 兜底 / 占位图），保证可看可交互；恢复即真调。
- **编排健壮性**：模型返回的 JSON 经 Schema 校验，缺失字段自动补齐；校验失败带错误反馈让模型重试一次，降低降级概率。
- **代理选型演进**：Cloudflare Worker（大陆不稳）→ Railway（大陆不稳）→ 腾讯云 SCF（国内可达），每一步都是真实踩坑后的取舍。
- **闭环设计**：生成 → 运行（拓扑顺序执行）→ 审核节点暂停进审片台 → 通过继续 / 打回从上游重做 → 发布到已授权渠道 → 运行记录留痕 → 首页统计复盘。

## 安全说明

- 所有 API Key（`COZE_API_KEY`、`LLM_API_KEY`、`DASHSCOPE_API_KEY`、`COGVIEW_API_KEY`、`COS_SECRET_KEY`、`ALIYUN_AK/SK`）**仅存于腾讯云函数环境变量**，本仓库代码只读取 `process.env.*`，不含任何真实密钥。
- 前端通过云函数代理调用，密钥永不进入浏览器。
- 合规审核默认走轻量规则引擎；配置 `ALIYUN_AK/SK` 后可一键升级为阿里云内容安全（绿网）真实 API。
