Skill 是平台的「能力原子」——每个视觉内容智能体由若干图像处理 / 内容 Skill 组合编排而成。下表为平台内置能力池（mock），覆盖电商、摄影、餐饮、地产、广告等多场景。
自定义 Skill 开发：用户可编写脚本扩展平台能力，配置入参 / 出参 Schema，经「发布校验」后上架到能力池，被任意生产线引用。

skill_remove_bg.pyPython 3.11
def run(inputs: dict) -> dict:
    # 商品图智能抠图 Skill：去背景→透明底图
    from PIL import Image
    import io, base64

    img = Image.open(io.BytesIO(
        base64.b64decode(inputs["image_base64"])))
    mask = remove_bg(img, mode=inputs["mode"])
    buf = io.BytesIO(); mask.save(buf, format="PNG")
    return {
        "transparent_png": base64.b64encode(
            buf.getvalue()).decode(),
        "width": img.width, "height": img.height
    }

素材库：生产线与各 Skill 的图像 / 视频输入源。支持按类型筛选与规格预览（替代通用「知识库」，更贴合视觉内容业务）。
全部 人像 商品 风光 视频
点击素材卡片选中，用于「运行」时作为本次生产线的输入素材
素材导入支持：本地拖拽上传、相机直传、网盘同步（演示入口，接入后素材库成为生产线的真实输入端）。
模板中心：覆盖电商、摄影、餐饮、地产、广告、自媒体等视觉内容场景的预设生产线，一键复用；也包含你从「生产线」存为模板的自定义生产线。每个模板由平台内置 Skill 编排而成，可在此基础上改。
交付管理：视觉内容团队追踪每条生产线的成片交付状态（客户审片 / 平台发布 / 内部使用）。状态由生产线节点的执行进度自动同步（如「合规审核」节点打回则标记为待重做）。待审片 / 已打回的项可一键跳转到「审片台」。
客户 / 项目类型产出进度状态操作
审片台：生产线「合规审核 / 客户审片」节点的专属处理界面。点击左侧待审项，看大图、写批注、通过或打回——这正是生产线「分支打回」闭环的人工落点。界面在窄屏下自动堆叠，支持外拍时手机审片。

从左侧选择一条待审片 / 待重做的成片。

运行记录：每条生产线历史的执行记录，含状态、耗时、消耗与节点级日志。对应 PRD 中的「评测体系」——跑真实数据、收集 Bad Case、反推优化（通过率 / 打回率 / 成本）。
